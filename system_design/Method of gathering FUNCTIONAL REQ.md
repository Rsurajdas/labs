###### Method of gathering **FUNCTIONAL REQUIREMENTS**



**NOT A GOOD APPROACH ->** "Ask the client to describe everything they need"



###### Powerful methods:

1. **Use Cases**

   * Situation / Scenario in which out system is used
2. **User Flows**

   * A Step-By-Step / Graphical representation of each use case



Requirement Fathering Steps:

1. **Identify** all the **actors/users** in our system
2. **Capture** and describe all the possible **use-cases/scenarios**
3. **User flow** - Expand each use case through flow of events.

   * Each event contains

     1. **Action**
     2. **Data**
