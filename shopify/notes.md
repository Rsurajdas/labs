### Templates Directory

The **`templates` directory** is where we create page templates. We can create **any number of templates** as needed.

### Sections Directory

The **`sections` directory** is where we create reusable sections, such as the **header, footer, and other page sections**.

### Assets Directory

The **`assets` directory** contains project assets such as **CSS files, JavaScript files, images, and other static resources**.

### Creating Variables in Liquid

Use the **`assign` keyword** to create and assign a value to a variable in a Liquid file.

```liquid
{% assign variable_name = 'value' %}
```

### Rendering Navigation Links

Use the **`linklists.main-menu.links` array** to loop through the main menu links and render the navigation items.
